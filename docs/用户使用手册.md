# 千川/抖店 × 飞书自动化 · 用户使用手册（零基础版）

> 目标：买完就能用。**不用敲命令、不用打开黑色终端。**

---

## 你将得到什么

每天早上 **08:00**（可改），电脑自动完成：

1. 轮询登录 **2 个抖店 + 多个千川账户**（演示版为模拟采集；正式版接真实后台）
2. 自动计算 **综合 ROI = 总 GMV / 千川总消耗**、付费占比等
3. 数据写入飞书多维表格预览 / 正式多维表
4. 飞书群推送 **漂亮的交互式日报卡片**（周一附周报，月初附月报）

---

## 第一次使用（只需 3 步）

### 第 1 步：安装依赖

双击项目根目录：

`一键安装依赖.bat`

等到提示「安装完成」即可。

### 第 2 步：打开控制台

双击：

`启动控制台.bat`

在窗口里填写：

- **飞书机器人 Webhook**（群设置 → 机器人 → 自定义机器人 → 复制地址）
- **多维表格链接**（可选，卡片底部按钮跳转用）
- 推送时间建议：`8` 时 `0` 分

点 **「保存配置」**。

### 第 3 步：立刻试一次

点 **「立即推送日报」**。

打开飞书工作群，应看到日报卡片。  
确认无误后，点 **「安装每天定时任务」**。

> 此后每天到点自动跑。电脑请保持开机，或放到云电脑挂机。

---

## 日常按钮说明

| 按钮 | 作用 |
|------|------|
| 保存配置 | 写入 `.env` |
| 立即推送日报 | 马上跑一遍完整流程 |
| 立即推送周报 | 推送周复盘卡 |
| 立即推送月报 | 推送近 30 天月报 |
| 安装每天定时任务 | 写入 Windows 任务计划 |
| 卸载定时任务 | 取消自动推送 |
| 演练模式 | 勾选后不真实发飞书，只写本地日志 |

---

## 挂机建议

- 家里闲置电脑：设置「从不休眠」
- 云电脑：几十元/月即可，关机则当天任务不会跑
- 日志位置：`logs/worker_日期.log`
