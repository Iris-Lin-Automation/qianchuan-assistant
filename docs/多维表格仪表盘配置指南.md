# 飞书多维表格仪表盘配置指南（方案 A）

目标：Python 跑完数据后写入多维表格，飞书仪表盘自动出柱状图/折线图/漏斗图；  
群卡片只放精简摘要 + 大按钮「📊 点击打开动态可视化仪表盘」。

---

## 一、在飞书里建表（5 分钟）

1. 新建【多维表格】，命名如：`千川经营数据中台`
2. 新建数据表：`日指标`
3. 按以下字段建列（名称必须一致，类型如下）：

| 字段名 | 类型 | 用途 |
|--------|------|------|
| 日期 | 日期 | 折线 X 轴 |
| 日期文本 | 文本 | 备用 |
| 店铺ID | 文本 | 筛选 |
| 店铺名称 | 文本 | 分组 |
| 千川消耗 | 数字 | 柱状/折线 |
| 成交GMV | 数字 | 柱状/折线 |
| 综合ROI | 数字 | KPI / 对比 |
| 转化成本CPA | 数字 | KPI |
| 付费占比 | 数字 | 占比图 |
| 展现量 | 数字 | 漏斗 |
| 点击量 | 数字 | 漏斗 |
| 订单量 | 数字 | 漏斗 |
| CTR | 数字 | 效率 |
| 退款率 | 数字 | 风险 |
| 评级 | 文本 | 标签筛选 |

4. 顶部「仪表盘」→ 新建仪表盘，建议组件：
   - KPI：总 GMV / 总消耗 / 综合 ROI / 订单量
   - 折线图：按「日期」看 GMV、消耗
   - 柱状图：按「店铺名称」看 ROI
   - 漏斗：展现 → 点击 → 订单
5. 右上角「分享」→ 复制链接，填进控制台「仪表盘/多维表链接」

---

## 二、自动写入（推荐）

1. 打开 [飞书开放平台](https://open.feishu.cn/app) 创建企业自建应用  
2. 开通权限：`bitable:app`（查看、评论、编辑和管理多维表格）  
3. 发布应用，并把应用添加为该多维表格的协作者（可编辑）  
4. 在控制台填写：
   - App ID / App Secret  
   - Bitable App Token（URL 里 `base/` 后面那段）  
   - Table ID（URL 里 `table=` 后面那段）  
5. 取消演练模式，点「立即推送日报」→ 数据进表 → 仪表盘自动刷新  

---

## 三、没有开放平台权限时（也能先做得很漂亮）

1. 控制台点「回填30天看板数据」  
2. 点「生成/打开本地仪表盘」→ 本地 Chart.js 看板（演示录屏够用）  
3. 或把 `data/bitable_daily_metrics.csv` **导入**飞书多维表格，再按上面组件搭仪表盘  

导入后的官方仪表盘视觉与大厂数据屏一致，这才是客户真正想要的「满屏高级图表」。

---

## 四、卡片怎么配合

日报卡片 = 评级 + 4 个核心指标 + 诊断摘要  
底部主按钮 = **📊 点击打开动态可视化仪表盘**（跳到你分享的仪表盘链接）

客户手机上看卡片决策；要深挖再点进仪表盘。
