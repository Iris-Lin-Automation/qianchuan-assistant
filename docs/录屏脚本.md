# 产品演示视频脚本（对着念就能拍）

总长建议：**2.5～4 分钟**（抖音可剪成 60～90 秒短版）  
原则：只拍「开箱 → 飞书群卡片 → 本地看板」，**不拍插件、不拍开发者后台、不拍黑窗口报错**。

文件位置：本仓库 `docs/录屏脚本.md`（客户交付包里也可放同款说明）。

---

## 一、录前准备（约 5 分钟）

| 项 | 怎么准备 |
|----|----------|
| 软件包 | 用**客户同款包**（解压后的「千川经营助手」文件夹）|
| Python | 已能双击 `一键安装依赖.bat` 到「安装完成」；装过就不用重装 |
| 飞书 | 电脑已登录；准备一个测试群 + 自定义机器人 Webhook |
| 样例数据 | 包里已有样例 Excel，演示不必登录真千川 |
| 录屏 | OBS / 剪映电脑版 / Win+G；1080p；鼠标指针调大 |
| 彩排 | 先跑通一轮：推送到群 + 能打开本地看板，再开录 |

口播可打字幕；等待安装时可快进。

---

## 二、镜头脚本（完整版 · 约 3 分钟）

### 镜头 1｜结果开场（0:00–0:20）

**画面**  
先切飞书群里一张已推好的日报卡片（指标、评级、建议都看得见）。

**口播**

> 很多老板不是不懂数据，是没时间每天登录抖店、千川对表。  
> 今天看一套：电脑到点自动算完，手机飞书群直接收到经营日报。

---

### 镜头 2｜痛点 10 秒（0:20–0:35）

**画面**  
快速闪：多个后台 / Excel / 计算器（静图也行）。

**口播**

> 人工导出容易漏，ROI 还要自己算，第二天又忘了。  
> 我们要的是：到点就推，刷手机就能决策。

---

### 镜头 3｜开箱安装（0:35–1:10）★

**画面**

1. 展示解压后的客户文件夹（文件名清晰）
2. 双击 `一键安装依赖.bat`（可快进到「安装完成」）
3. 双击 `启动控制台.bat`，操作台弹出

**口播**

> 客户这边不用敲任何代码。  
> 解压，点安装，再打开操作台就行。  
> （已装过依赖的，这一步可跳过，直接进配置。）

---

### 镜头 4｜配置 + 推送（1:10–2:10）★核心

**画面**

1. 操作台粘贴「飞书群机器人地址」→ 点「保存配置」
2. 双击 `一键体验演示.bat`（或操作台点「立即推送日报」）
3. 切到飞书群：卡片进来（标题、消耗、GMV、ROI、评级、建议）
4. **回到操作台**，点「打开经营看板」→ 浏览器打开本地图表（不要指望卡片里一定有本地看板按钮）

**口播**

> 保存一次机器人地址，点一下推送。  
> 群里这张卡片是早上决策摘要。  
> 要看图表：在操作台点「打开经营看板」，本机就会打开可视化页面。

> 小提示（口播可省略、字幕可加）：  
> 飞书卡片里不好直接打开电脑本地文件，所以图表统一在操作台打开，更稳定。

---

### 镜头 5｜正式每天怎么跑（2:10–2:40）

**画面**  
指一下文件夹里的 `data\today.xlsx`，或快速扫一眼「影刀对接说明」。

**口播**

> 正式用：影刀每天定时登录导出，保存成 today 这个表，  
> 最后一步调用「影刀调用 Python」，群里就会自动叮一声。  
> 也可以在操作台开每日定时，电脑挂机即可。  
> 录像用的是样例数据，流程和真店一模一样。

---

### 镜头 6｜收单（2:40–3:00）

**画面**  
操作台窗口 + 飞书卡片并排（分屏或切一下）。

**口播**

> 交付包含：开箱软件、飞书机器人配置协助、影刀对接指导。  
> 需要的老板私信「千川日报」，按店铺数量报价开通。

---

## 三、抖音短版（60～90 秒）

| 秒数 | 画面 | 口播一句 |
|------|------|----------|
| 0–8 | 飞书卡片特写 | 「每天早上，经营日报自动进飞书群。」 |
| 8–20 | 解压 + 点安装（快进） | 「不用写代码，解压点一下就能用。」 |
| 20–45 | 保存 Webhook → 推送 → 群消息 | 「填一次机器人地址，立刻出卡片。」 |
| 45–70 | 操作台打开经营看板 | 「图表在本地点开经营看板就能看。」 |
| 70–90 | 操作台+卡片合影 | 「私信『千川日报』开通。」 |

---

## 四、拍摄口令卡（打印贴显示器旁）

```
1. 先录飞书卡片结果
2. 再录客户包文件夹
3. 一键安装（可快进）→ 启动控制台
4. 粘贴 Webhook → 保存
5. 一键体验演示 → 切群看卡片
6. 操作台 → 打开经营看板
7. 口头带过影刀 + today.xlsx
8. 收单话术结束
```
