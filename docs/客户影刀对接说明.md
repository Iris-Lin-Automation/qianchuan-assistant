# 影刀对接说明（客户版）

## 每天自动流程

```
影刀定时启动
  → 登录抖店 / 千川
  → 导出 Excel
  → 保存为：本软件目录\data\today.xlsx
  → 最后一步运行：影刀调用Python.bat
  → 飞书群收到经营日报
```

---

## 影刀里这样配

1. **定时**：例如每天 08:00  
2. **导出**：在千川/抖店后台导出当日数据  
3. **保存路径**（务必一致）：  
   `本软件解压目录\data\today.xlsx`  
4. **最后一步**：运行应用程序  
   - 程序：`影刀调用Python.bat`（完整路径）  
   - 工作目录：本软件解压目录  

完成后无需再打开黑窗口，群里会自动收到卡片。

---

## 兼容文件名

如果影刀先保存成 `data\qianchuan_today.xlsx`，软件会自动当作今天的报表处理。
