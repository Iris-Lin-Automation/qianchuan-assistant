# 使用手册（开箱即用）

买完就能用，不需要敲命令。

## 你将得到什么

每天定时自动：

1. 读取影刀导出的经营 Excel  
2. 计算消耗、GMV、ROI 等关键指标  
3. 把日报卡片推到飞书群  
4. 本地点「打开经营看板」即可看图表  

---

## 第一次使用（3 步）

### 第 1 步：安装

双击：`一键安装依赖.bat`  
等到提示「安装完成」。

### 第 2 步：填写配置

双击：`启动控制台.bat`

- **飞书群机器人地址**（群设置 → 机器人 → 自定义机器人 → 复制 Webhook）  
- **每天自动推送时间**（电脑本机时间，默认 8:00）  

图表不在飞书卡片里点开，请用控制台「打开经营看板」。

点 **「保存配置」**。

### 第 3 步：先体验一次（可选）

双击：`一键体验演示.bat`  
到飞书群看是否收到日报。

---

## 日常正式使用

1. 影刀每天导出报表，保存为：`data\today.xlsx`  
2. 影刀最后一步运行：`影刀调用Python.bat`  
3. 或在控制台点「立即推送日报 / 开启每日定时」

---

## 常见问题

- 群里没有消息：检查机器人地址是否填对，再用「一键体验演示」测一次  
- 提示找不到 today.xlsx：确认影刀保存路径是本文件夹下的 `data\today.xlsx`  
- 想看图表：控制台点「打开经营看板」
