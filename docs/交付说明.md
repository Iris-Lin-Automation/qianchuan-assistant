## 客户开通 SOP（你交付时照着做）

1. 把整个文件夹压缩发给客户（可去掉 `.venv`，让客户本地点「一键安装依赖」）
2. 视频/远程协助：帮客户建飞书群机器人，复制 Webhook
3. 控制台保存配置 → 立即推送日报确认
4. 安装每天 08:00 定时任务
5. 告知：周一自动带周报，每月 1 号带月报
6. 交付「用户使用手册」+ 1 个月维护承诺说明
