# 交付边界：客户包 vs 仓库内 extension 插件

## 仓库现在长这样（按你的要求）

```
qianchuan-feishu-analytics/
├── extension/                  ← 飞书「数据表视图」插件（Cursor 一起改）
│   ├── app.json
│   ├── dashboard/
│   │   ├── block.json
│   │   └── src/                ← 看板 React 代码
│   ├── 填写AppID.bat
│   └── 上传插件.bat
├── main.py
├── app_gui.py
├── 影刀调用Python.bat
└── ...
```

> 比示意多一层 `dashboard/`：这是 `opdev upload` 找 `app.json` + 子目录 `block.json` 的官方结构。  
> 你日常改代码就改 `extension/dashboard/src`。

---

## 给客户 / 不给客户

| 内容 | 客户 zip | 说明 |
|------|----------|------|
| Python + 影刀 + GUI + data 模板 | ✅ | `scripts\pack_customer.ps1` |
| `.venv` / `logs` | ❌ | 客户本机「一键安装依赖」 |
| `extension/**/node_modules` | ❌ | 只在你电脑 `npm install` |
| `extension/` 源码 | ❌（默认） | 插件你发布后，客户飞书内添加即可 |

---

## 省磁盘

- 以前误建的 `D:\my-app` 可整夹删除（代码已迁到本仓库 `extension/`）
- 插件依赖只装在：`extension\dashboard\node_modules`，不用可删掉该文件夹

---

## 你本地继续插件开发

```bat
cd /d D:\qianchuan-feishu-analytics\extension
填写AppID.bat

cd dashboard
npm install
npm run start
```

上传：双击 `extension\上传插件.bat` 或在 dashboard 里 `npm run upload`
